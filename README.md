# Design-an-FSM-Controller-for-a-Turing-Machine
Design an FSM Controller for a Turing Machine to verify whether parentheses on the input tape are balanced. If the string is balanced, the machine halts with an output of 1, if unbalanced, it halts with an output of 0

_The TMsim.jar file was used to execute the Turing machine simulation, while FSM_control.txt contains the code defining its control logic._

_Complete test cases, execution traces, and explanations for each scenario are documented in Lab4.docx_
